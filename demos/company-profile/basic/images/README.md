# Nusantara Rice Distribution - Images Directory

Letakkan gambar website Anda di folder ini. Contoh struktur:

- `hero.jpg` - Gambar hero utama (karung beras)
- `about.jpg` - Gambar gudang
- `product-premium.jpg` - Gambar beras premium
- dll.

Website saat ini menggunakan gambar placeholder dari Unsplash. Untuk mengganti dengan gambar lokal, cukup ubah atribut `src` gambar pada file HTML.
